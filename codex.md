# Codex (and any non-Cursor agent)

**Bootstrap:** Read **`AGENTS.md`** first (Popcorn loop, `HISTORY.md` protocol).

Then open **`HISTORY.md`** for the latest iteration, numbers, failures, and **Next bet**.

For low-level kernel optimization, read **`docs/mi355x_isa_reference.md`** (MFMA instructions, memory ops, novel techniques).

Cursor loads **`.cursor/rules/agents-history.mdc`** automatically; this file exists so **Codex CLI** and other tools have a single pointer without that machinery.

**Humans:** optional; this file is for agent entry points.
